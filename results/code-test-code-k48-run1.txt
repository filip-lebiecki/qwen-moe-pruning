Q: Write a Python function fib(n) that returns the n-th Fibonacci number iteratively, with fib(0) = 0 and fib(1) = 1.
A: Here's a Python function `fib(n)` that returns the n-th Fibonacci number iteratively:

```python
def fib(n):
    if n < 0:
        raise ValueError("Fibonacci numbers are defined for non-negative integers.")
    
    if n == 0:
        return 0
    if n == 1:
        return 1
    
    a, b = 0, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    
    return b
```

### Explanation:
- **Base cases**:  
  - `fib(0) = 0`  
  - `fib(1) = 1`  
- **Iterative approach**:  
  - Start with `a = 0` (fib(0)) and `b = 1` (fib(1)).  
  - For each step from 2 to n, update:  
    - `a` becomes the previous `b`  
    - `b` becomes the sum of the old `a` and `b`  
  - After the loop, `b` holds `fib(n)`.

This runs in O(n) time and O(1) space.

Q: Write a Python function is_palindrome(s) that returns True if s reads the same forwards and backwards, ignoring case and any character that is not a letter or digit.
A: Here is a Python function that checks if a string is a palindrome, ignoring case and non-alphanumeric characters:

```python
def is_palindrome(s):
    # Filter out non-alphanumeric characters and convert to lowercase
    cleaned = ''.join(char.lower() for char in s if char.lower().isalnum())
    
    # Check if the cleaned string is equal to its reverse
    return cleaned == cleaned[::-1]
```

This function:
1. Filters the string to keep only alphanumeric characters (letters and digits)
2. Converts them to lowercase for case-ins comparison
3. Compes the cleaned string with its reverse to check if it reads the same forwards and backwards

Example usage:
```python
# Test cases
print(is_palindrome("raceca"))  # True
print(is_palindrome("raceca"))  # True
print(is_palindrome("raceca"))  # True
print(is_palindrome("raceca"))  # True
print(is_palindrome("raceca"))  # True
```
