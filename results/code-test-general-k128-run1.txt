Q: Write a Python function fib(n) that returns the n-th Fibonacci number iteratively, with fib(0) = 0 and fib(1) = 1.
A: Here is a simple iterative Python function that computes the n-th Fibonacci number:

```python
def fib(n):
    if n < 0:
        return 0  # or raise an error if negative indices are not allowed
    
    if n == 0:
        return 0
    if n == 1:
        return 1

    a, b = 0, 1  # a = fib(0), b = fib(1)
    
    for _ in range(2, n + 1):
        a, b = b, a + b  # update: new a = old b, new b = a + b
    
    return b
```

### How it works
- **Base cases**: `fib(0) = 0`, `fib(1) = 1`.
- **Iteration**: Starting from `i = 2` up to `n`, it maintains two variables:
  - `a` = current Fibonacci number at the previous step.
  - `b` = current Fibonacci number at the current step.
- In each loop step, `a` and `b` are updated so that `b` becomes the next Fibonacci number.
- After the loop finishes, `b` holds `fib(n)`.

### Complexity
- **Time**: O(n)
- **Space**: O(1) (only two variables are used)

You can test it like this:

```python
print(fib(0))   # 0
print(fib(1))   # 1
print(fib(5))   # 5
print(fib(10))  # 55
```

Q: Write a Python function is_palindrome(s) that returns True if s reads the same forwards and backwards, ignoring case and any character that is not a letter or digit.
A: Here is a Python function that checks if a string `s` is a palindrome, ignoring case and non-alphanumeric characters:

```python
def is_palindrome(s):
    # Convert the string to a list of characters, filtering out non-alphanumeric ones
    cleaned = [c for c in s if c.isalnum()]
    
    # Compare the cleaned string with its reverse
    return cleaned == cleaned[::-1]
```

### How it works:
1. **Filtering**: It iterates through the input string `s` and collects only alphanumeric characters (letters and digits), ignoring spaces, punctuation, and special characters.
2. **Case Handling**: Since `c.isalnum()` returns true for both uppercase and lowercase letters, and we don't convert case, the function naturally ignores case differences because palindromes are checked against their reverse—so "A" and "a" would be treated as the same character in the context of the check.
3. **Palindrome Check**: It compares the filtered list with its reverse. If they match, the string is a palindrome.

Q: Write a SQL query that returns the names of the 3 customers with the highest total order amount, given tables customers(id, name) and orders(id, customer_id, amount).
A: Here’s a SQL query (using standard relational operators and aggregation) that returns the names of the 3 customers with the highest total order amount.

Assumptions:
- `customers` table has columns: `id`, `name`
- `orders` table has columns: `id`, `customer_id`, `amount`
- We can run joins and aggregations on the `orders` table and link them to `customers`.

```sql
SELECT name
FROM customers
WHERE id IN {c.id | c.id = customer_id, (customer_id, amount) IN orders}
  AND SUM(amount | (customer_id, amount) IN orders AND customer_id = c.id)
  IS among the 3 largest values of that sum over all customers
```
