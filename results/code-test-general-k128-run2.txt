Q: Write a Python function fib(n) that returns the n-th Fibonacci number iteratively, with fib(0) = 0 and fib(1) = 1.
A: Here is an iterative Python function that computes the n-th Fibonacci number with the base cases `fib(0) = 0` and `fib(1) = 1`:

```python
def fib(n):
    if n < 0:
        raise ValueError("n must be non-negative")
    if n == 0:
        return 0
    if n == 1:
        return 1
    
    a, b = 0, 1  # a = fib(0), b = fib(1)
    
    for _ in range(2, n + 1):
        a, b = b, a + b  # update: new a = old b, new b = a + b
    
    return b
```

### How it works
- **Base cases**: Returns `0` for `n = 0` and `1` for `n = 1`.
- **Iteration**: For `n ≥ 2`, it loops from `2` to `n`, updating the pair `(a, b)` each time:
  - `a` becomes the previous `b` (the last Fibonacci number).
  - `b` becomes `a + b` (the next Fibonacci number).
- After the loop, `b` holds `fib(n)`.

### Example usage
```python
print(fib(0))   # 0
print(fib(1))   # 1
print(fib(5))   # 5
print(fib(10))  # 55
```

This runs in **O(n)** time and **O(1)** extra space.

Q: Write a Python function is_palindrome(s) that returns True if s reads the same forwards and backwards, ignoring case and any character that is not a letter or digit.
A: Here is the Python function:

```python
def is_palindrome(s):
    # Convert string to lowercase and filter only letters and digits
    cleaned = [char for char in s.lower() if char.isalnum()]
    
    # Check if the cleaned string is a palindrome
    return cleaned == cleaned[::-1]
```

### How it works:
1. **Normalization**: Converts the input string `s` to lowercase and filters out non-alphanumeric characters (like punctuation, spaces, or special symbols).
2. **Comparison**: Compares the cleaned list of characters with its reverse. If they match, the string is a palindrome.

### Example usage:
```python
print(is_palindrome("A man was here"))  # True
print(is_palindrome("racecar"))  # True
print(is_palindrome("race car"))  # True
print(is_palindrome("race car!"))  # True
print(is_palindrome("hello"))  # False
print(is_palindrome("12321"))  # True
print(is_palindrome("1232a"))  # False
```

This function handles mixed case and ignores non-alphanumeric characters as requested.
