Q: Write a Python function fib(n) that returns the n-th Fibonacci number iteratively, with fib(0) = 0 and fib(1) = 1.
A: Here is a Python function that calculates the n-th Fibonacci number iteratively:

```python
def fib(n):
    if n < 0:
        return None  # or 0, depending on desired behavior for negative n
    
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

### How it works:
- **Base cases**: `fib(0)` returns `0`, `fib(1)` returns `1`.
- **Iteration**: For each step from `0` to `n-1`, the function updates the pair `(a, b)` where `a` is the current Fibonacci number and `b` is the next one.
- **Efficiency**: Time complexity is **O(n)** and space complexity is **O(1)**.

### Example:
```python
print(fib(10))  # Output: 55
```

Q: Write a Python function is_palindrome(s) that returns True if s reads the same forwards and backwards, ignoring case and any character that is not a letter or digit.
A: Here is a Python function that checks if a string `s` is a palindrome, ignoring case and non-alphanumeric characters:

```python
def is_palindrome(s):
    # Convert the string to a list of valid characters
    valid_chars = [c for c in s if c.isalnum()]
    
    # Convert to lowercase to ignore case
    valid_chars = [c.lower() for c in valid_chars]
    
    # Check if the list of characters is a palindrome
    return valid_chars == valid_chars[::-1]
```

### How it works:
1. **Filter**: Keeps only alphanumeric characters (letters and digits).
2. **Normalize**: Converts them to lowercase to ignore case differences (e.g., 'A' and 'a' are treated the same).
3. **Compare**: Checks if the filtered list reads the same forwards and backwards.

### Example Usage:
```python
print(is_palindrome("A man, a woman, and a dog."))  # True
print(is_palindrome("racecar"))  # True
print(is_palindrome("racecar "))  # True
print(is_palindrome("hello"))  # False
print(is_palindrome("121"))  # True
print(is_palindrome("123"))  # False
print(is_palindrome("Madam, 12345, 12345, Madam"))  # True
```

*Note: In the last example, the string contains repeated "12345" which is ignored, leaving "Madam" which is a palindrome.*
