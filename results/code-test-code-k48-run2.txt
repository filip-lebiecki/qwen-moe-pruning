Q: Write a Python function fib(n) that returns the n-th Fibonacci number iteratively, with fib(0) = 0 and fib(1) = 1.
A: Here is the Python function `fib(n)` that calculates the n-th Fibonacci number iteratively:

```python
def fib(n):
    if n == 0:
        return 0
    if n == 1:
        return 1
    
    a, b = 0, 1
    for i in range(2, n + 1):
        a, b = b, a + b
    return b
```

### Explanation:
- **Base cases:**
  - `fib(0) = 0`
  - `fib(1) = 1`
- **Iterative approach:**
  - Start with `a = 0` (F₀) and `b = 1` (F₁).
  - Loop from 2 to n.
  - Update `a, b = b, a + b` (shifts current values to next Fibonacci number).
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)

This function avoids recursion and efficiently computes the nth Fibonacci number.

Q: Write a Python function is_palindrome(s) that returns True if s reads the same forwards and backwards, ignoring case and any character that is not a letter or digit.
A: Here is a Python function `is_palindrome(s)` that returns `True` if the input string `s` reads the same forwards and backwards, ignoring case and non-alphanumeric characters:

```python
def is_palindrome(s):
    # Filter out non-alphanumeric characters and convert to lowercase
    cleaned = ''.join(char.lower() for char in s if char.lower().isalnum())
    
    # Check if the cleaned string is equal to its reverse
    return cleaned == cleaned[::-1]
```

### Explanation:
- The function first filters the input string `s` to keep only alphanumeric characters (letters and digits).
- Each character is converted to lowercase.
- The filtered string is then compared to its reverse to check if it is a palindrome.
