Pruning Qwen3.5-35B-A3B

How a 35 B Mixture-of-Experts model became a 19 B model that runs at 190 tokens per second on one 16 GB GPU, explained from scratch. Each chapter matches one section of the project README and uses this project's real numbers wherever they exist.

New here? Start with the learning path → six short tracks through all the pages, a cheat sheet of the key numbers, and questions at the end of every chapter.

How to use these pages

Each chapter has an animation that plays step by step. Use Play, Next and Back, the step dots, or the arrow keys and space bar. Below it, a Try it panel lets you change one thing and see the effect. Colors keep one meaning everywhere: blue for hidden states and tokens, amber for active experts, teal for kept, red for pruned or errors, violet for the router.

The full written notes, with every command, the results tables and what each run taught, are in the project notes. Each chapter links to its section there.

The pages are plain files: open learn/index.html in any browser. Fonts load from Google Fonts when online and fall back to system fonts otherwise.
