Chapter 12

The whole pipeline

Everything from the previous chapters, in the order the scripts run it in run 2: from a 67 GiB download to an 11 GB file that answers at 190 tokens per second on a 16 GB GPU.

After this pipeline

The stages above are run 2. The same scripts with other settings, plus a few new ones, made the rest of the project:

  • Run 3, code specialist: 02_calib_data.py --preset code, run_code_sweep.sh, 04_prune.py --stats stats/code.pt --keep 48, CALIB=data/calib_code.pt 07_gguf.sh (appendix D).
  • Step 2, benchmarks: download_baseline.sh, run_bench.sh → 08_bench.py, bench_report.py (appendix E).
  • Step 3, distillation: 02_calib_data.py --preset train, 09_teacher_logits.py, 10_distill.py, 11_patch_gguf.py, distill_report.py (appendix F).
  • Experiments: 12_expert_tokens.py (appendix G) and 13_layer_sensitivity.py (a different K per layer, in the project notes).
  • Step 4, the quantization curve: 14_quant_sweep.sh → 15_measure_gguf.sh → speed_test.py, run_bench.sh; quant_report.py (appendix H).
  • Step 5, ablation and merging: 02_calib_data.py --preset domains, run_step5.sh → 16_ablate.py, 17_expert_similarity.py, 05_eval.py --merge; ablation_report.py (appendix I).
  • Foundations (chapters 13–16): kv_memory.sh (KV cache per context), batch_speed.py (throughput against parallel requests), number_formats.py (real weights and activations), theory_report.py (writes the chapters' data).
  • Step 6, practical: make_gguf.sh (any HF model to checked GGUF files), offload_sweep.sh (a MoE bigger than the GPU), model_card.py, upload_gguf.sh, practical_report.py (appendix J).
  • Step 7, speculative decoding: spec_sweep.sh → spec_test.py, and llama-bench -p 1,2,4,8,16 for the cost of checking N tokens (chapter 15).
