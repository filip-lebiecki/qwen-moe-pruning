How to study with these pages

One chapter at a time. Watch the animation with Play, then step back through it with the arrow keys; then use the "Try it" panel to change one thing and predict the result before you look.

Answer before you open. The questions at the end of each page are short on purpose; if you cannot answer one, reread that part of the page or its README section, not the answer.

Run one thing yourself. The fastest way to make it stick is to run a command from the notes: scripts/make_gguf.sh Qwen/Qwen3.5-2B Q4_K_M takes about 4 minutes and touches download, conversion, the imatrix, quantization and perplexity.

Read anywhere. The pages are published at filip-lebiecki.github.io/qwen-moe-pruning/learn/, and the scripts and results are at github.com/filip-lebiecki/qwen-moe-pruning. Ticks made on the website and ticks made in the local files are kept separately.
