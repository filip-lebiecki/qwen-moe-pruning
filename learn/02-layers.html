Layers

The model is a stack of 40 decoder layers. Each one reads every token's hidden state, adds a correction, and passes it on. Knowing this shape explains both how we can run a 67 GiB model on a 16 GB GPU and why pruning errors pile up.

Try it: how a small error travels

layer 3

Illustration, not a measurement: each layer passes the deviation on and slightly amplifies it. The residual stream never "forgets" a wrong correction. Later layers read it and build on it.

What to remember

Every layer has the same two halves. The token mixer lets tokens exchange information (Gated DeltaNet in 30 layers, full attention in 10, in a repeating 3:1 pattern). The feed-forward part works on each token alone, and in this model it is the Mixture of Experts. RMSNorm rescales the vector before each half.

The residual connection means each half only adds to the hidden state. Two consequences: to run layer 17 you need only layer 17's weights and the hidden states that came out of layer 16, which is how moe_stream.py streams the model one layer at a time. And an error made in layer 3 is still in the hidden state at layer 39 ("drift").
