Attention, Gated DeltaNet and the KV cache

The MoE half of a layer works on each token alone; the token mixer is where tokens exchange information. Qwen3.5 uses exact attention in 10 of its 40 layers and a fixed-size memory, Gated DeltaNet, in the other 30. This page shows how both work, why attention needs a cache that grows with every token, and what that costs on a 16 GB card.

What to remember

Attention: each token turns its hidden state into a query, a key and a value; it compares its query with the keys of all earlier tokens, softmaxes the scores and averages their values. Exact, but the work and the memory grow with the length of the text.

The KV cache stores the keys and values of past tokens so they are computed once. Here it costs 20 KiB per token (10 attention layers x 2 x 2 KV heads x 256 numbers x 2 bytes): 640 MiB at 32k tokens, 5 GiB at the full 262k. An 8-bit cache halves that and makes the full context fit on 16 GB.

Gated DeltaNet keeps a fixed 128 x 128 memory per head instead, updated by the delta rule: erase what is stored under the token's key, write its value there, and let a gate decide how fast old content fades. 60 MiB for all 30 layers, at any length; the price is that old details blur, which the 10 exact attention layers make up for.
